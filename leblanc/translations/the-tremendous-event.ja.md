# 驚天の大事件（The Tremendous Event）— 推理分析

## 基本情報
- 著者：モーリス・ルブラン（Maurice Leblanc）
- 発表年：1922年
- ジャンル：長編冒険推理小説
- 探偵：なし（主人公 Simon Dubosc がアクションヒーローとアマチュア推理家を兼ねる）

## あらすじ

1922年、英仏海峡が古代の地質断層（ルブランが「ルーアン断層」と呼ぶもの）により突然隆起し、フランスのディエップ（Dieppe）からイングランドのヘイスティングス（Hastings）を結ぶ新たな陸地——「ノルマンジー地峡」が形成された。これはヨーロッパの政治地理を一変させる世紀の大事件である。

フランスの青年 Simon Dubosc はイギリス貴族の娘 Isabel Bakefield に求愛しているが、父親から「まず英雄的偉業を成し遂げてから婚約を話し合おう」と断られている。大地震の夜、Simon は海面に浮上した新陸地を徒歩でイングランドまで渡り、「海峡を徒歩で最初に横断した人物」となった。

しかしこの旅の途中で、次々と謀殺事件が起きる：
- インド系俳優 Badiarinos が新陸地で背中を刺されて死亡、現場にはゴム底靴の足跡とナポレオン金貨一枚が残される
- Isabel から Simon への密書が奪われ、使者（侍女）が Simon の使者を名乗る「Rolleston氏」に手紙を渡してしまう
- 手紙を持つ者が Simon を暗殺しようとするが、隣の部屋（43号室ではなく44号室）の無実の宿泊客を誤って刺してしまう

疑惑は Simon のイングランドの友人 Edward Rolleston に向けられる——彼は酒に溺れ、行動が定まらない人物だ。しかし Simon の直感は旧友を犯人とは信じられない。

真実は：その人物は Edward ではなく、彼のいとこ Wilfred Rolleston——外見がよく似ていながら、アルコール中毒の偏執的な犯罪者へと堕落した男だった。Wilfred は Isabel を欲し、ならず者を集め、Lord Bakefield 父娘を誘拐し、新陸地の廃棄船上で君臨し、黄金の泉で無法者の軍団を支配していた。

Simon はインド系混血俳優 Antonio（Lynx-Eye）と組んで救出作戦を展開。途中、謎めいたメキシコ系女優 Dolores とも関わることになる——彼女は Simon へ恋心を抱き、故意に追跡ルートを誤誘導していた。最終的に Simon は墜落した飛行機を修理して戦場へと飛び、Antonio の協力のもと Isabel を救出。仏英両軍の衝突を防ぎ、「新領土高等弁務官」となった。

### 真相一：殺人者の正体——Edward Rolleston ではなく Wilfred Rolleston（whodunit）

- **手がかり収束点：約55%**
- 答え：犯人は Wilfred Rolleston、Edward のいとこ。二人の外見は非常によく似ているが、性格は正反対だ。Wilfred はアルコール中毒の偏執的な犯罪者に堕ち、背後から刺すという方法で殺人を行う（長身のため、上から俯角で刺すことができる）。

### 真相二：信書はどのように奪われ、Simon はなぜ誤って刺されたのか（howdunit）

## 推理経路の再構成

**第一の経路：「Rolleston」の真の正体を見破る**

読者は41%あたり（Antonio が金貨のつながりを暴く、犯人の描写が完成する）で、相互に矛盾する二つの情報を持っている：
1. 犯人は「Rolleston」だ（物証：金貨、ゴム靴底）
2. Simon は Edward Rolleston が無実だと固く信じている（性格の手がかり：Simon への真の友情）

この二つの情報自体が重要な推理の分岐点を構成している：**Simon の判断が正しければ、別の「Rolleston」が存在しなければならない**。このとき注意深い読者が Antonio の犯人描写（背が高く、青白く、猫背）と Edward の外見が一致することに気づけば、外見がそこまで似ている人物はイングランドでは近親族である可能性が高いと察することができるはずだ。

55%の地点（怪我をした Edward が残骸の傍にいる、Antonio が「彼は別人だ」と確認する）で手がかりが完全に収束し、いとこ Wilfred の身元がようやく確実に推論可能となる。

**第二の経路：手紙奪取の謎**

金貨が最も重要な物的連結だ。Antonio が侍女から受け取ったチップの金貨（ナポレオン1807年版）と Simon が謀殺現場で拾った金貨が完全に一致することを示すと、読者は41%あたりで推導できる：

> 殺人者 = 手紙を奪った人物 = 間違った部屋の宿泊客を刺した人物

手紙を奪った動機（ミニチュア肖像の存在を知った + Simon が恋敵であることを知った）も同時に明確になる。

**第三の経路：Dolores の裏切り**

この経路は最も解読が難しい。なぜなら作者は彼女の感情的な伏線を「献身と保護」という外套で包んでいるからだ。鍵となるのは彼女の足跡——Simon は物的証拠から「彼女が Rolleston の野営地を一人で訪れていたのに、自分には言わなかった」と推断する。この推理が実行可能になるのは63%の段階で、読者が彼女の早前の発言「今朝私は周囲の地形を調査した」（Part 2 Ch.2の冒頭）を覚えており、その後の足跡の発見と照らし合わせて初めて、彼女が知っていながら報告しなかった事実を組み立てることができるからだ。

## 補足説明

**これは純粋な推理小説ではない——推理という外衣をまとった冒険叙事詩だ**

『驚天の大事件』はジャンル的にはエドワード朝の冒険小説に近く、古典的な推理小説ではない。ルブランは推理要素（謀殺、身元の誤誘導、陰謀）を地殻大災害という宏観な背景の中に埋め込み、独特の読書体験を生み出した：読者は「誰が犯人か」と「英仏海峡全体が崩壊しつつある」という二つの次元の緊張感に同時に対応しなければならない。

この設計により謎の推理的プレッシャーは相対的に低くなっている——読者の注意が奇観（新陸地、黄金の泉、廃船の王国）に分散されるからだ——しかしそれゆえに謎の解明がより感情的な衝撃力を持つことにもなる。

**身元の置き換え：二人の Rolleston の設計**

ルブランは『アルセーヌ・ルパン』シリーズで「完璧な変装」で知られているが、本作ではより優雅な手法を用いた——**変装など全く必要としない**のだ。Wilfred と Edward の外見は自然に似ており、すべての目撃者（Antonio、侍女）の描写が Edward を指すようになっているが、実際は別の人物だ。この「先天的な誤誘導」の設計は、どんな精巧な変装よりも説得力がある。なぜなら目撃者の描写は真実であり、対象が混同されているだけだからだ。

この手法はその後の推理文学で広く用いられるようになったが、1922年の作品として先見の明があると評価されるべきだろう。

**Dolores というキャラクター：推理を超えた文学的意義**

Dolores は全作品の中で最も複雑な人物であり、悪役の Wilfred よりも立体的だ。彼女の「裏切り」は実際には愛の盲目さにすぎず、最終的に彼女は自己の利益を犠牲にし、一人でフランス軍に助けを求めに行き、Simon と Isabel の命を救う——この結末が彼女の「わがまま」を昇華させる。

最後に彼女が無言で馬に乗り去り、Simon に目線さえ向けない場面は、ルブランが1920年代に書いた希少な現代的女性像だ：彼女はすべてを捧げたが、いかなる男の付属品になることも拒んだ。

**ルブランの他作品との比較**

| | アルセーヌ・ルパンシリーズ | 驚天の大事件 |
|--|--|--|
| 核心ミステリー | 詐欺 / 窃盗 / 身元の謎 | 謀殺 / 身元の誤誘導 |
| 主人公の性質 | 紳士泥棒（正邪混交） | 正直な英雄（純粋な善良さ） |
| 世界観 | パリ上流社会 | 地質大災害後の無政府荒野 |
| 叙事の野心 | 精妙なプロット機構 | 地政学的寓話 + 個人英雄主義 |

本作はルブランの稀なる「正面の英雄」作品だ——Simon Dubosc には道徳的な曖昧さが全くなく、完全に真っ当な人物である。これにより推理のサプライズ感は下がる（アルセーヌ・ルパン式の「誰が善人で誰が悪人か」という逆転がない）が、物語の感情的な重心はより明確だ。

**読者への時代的補足**

本書は1922年に出版され、その時点で英仏「海峡トンネル」の構想は数十年間流布していた（最終的に1994年に完成）。ルブランは「人工海底トンネル」の夢を「自然の地質災害が作り出した陸橋」へと転化した——これは巧みなSF的変換だ。書中の新陸地の描写（海底堆積物、古い貝殻層、太古の人類の痕跡）は、ルブランが地質学を真剣に研究したことを示しており、「老砂岩教授」の口を借りた断層構造の解説は、1920年代としては相当通俗的で正確な科学普及だった。

黄金の泉の設定（古代の沈没船の宝が地熱噴泉によって海底から噴き出される）は豪快なロマン主義を帯びている——これは真剣な推理小説ではほとんど登場しえない要素だが、ルブランは読者を納得させてしまう。それ自体が一つの偉業だ。
