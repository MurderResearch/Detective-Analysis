金髮女郎（The Blonde Lady）— 推理分析

基本資訊

  • 作者：莫里斯·盧布朗（Maurice Leblanc）
  • 出版年：1907年（法文原版《Arsène Lupin contre Herlock Sholmès》）；1910年英譯本出版
  • 類型：長篇小說（含兩個獨立篇章）
  • 偵探角色：霍姆洛克·謝爾斯（Holmlock Shears，夏洛克·福爾摩斯之戲謔化身），輔以法國警探加尼瑪（Ganimard）
  • 核心謎團類型：whodunit × howdunit × wherefound——三種謎型並陳，疊床架屋

故事大綱

第一篇章：金髮女郎（The Blonde Lady）

一切從一張彩票開始。凡爾賽數學教授熱爾博瓦偶然買下一張中獎號碼的彩票，未料號碼記錄連同彩票一道，被人盜走了書桌。盜賊隨即揭曉身份：亞森·羅蘋。百萬法郎的彩票此後成為二人之間赤裸的談判籌碼，羅蘋挾持熱爾博瓦之女蘇珊為人質，逼教授就範，分走五十萬。

同一時期，另一樁血案在巴黎亨利·馬丁大道震驚輿論：退休外交官德·奧特雷克男爵陳屍臥室，稀世珍寶「藍鑽」（前法國皇室御寶）仍戴在死者手指，而兇手無影無蹤。調查顯示，一名叫作「安托瓦內特·布雷阿」的女伴遁走，頭髮色澤恰與在熱爾博瓦案中目擊的金髮女郎吻合。

接著是拍賣會上的怪事：土豪買家赫旭曼正要出高價競拍藍鑽時，一封神秘便條令他在決定性瞬間分心，藍鑽落入德·克羅宗伯爵夫人手中；六個月後，伯爵夫人的夏日別墅裡，藍鑽再度失竊——最終在奧地利領事布萊興的牙粉瓶中被「尋回」。

此時倫敦名探霍姆洛克·謝爾斯（福爾摩斯戲謔版）受委託介入，大戰展開。謝爾斯偵查一條關鍵線索：三個犯案地點——律師德蒂南的公寓（克拉帕依宏路）、男爵的老宅（亨利·馬丁大道134號）、克羅宗城堡——皆由同一建築師呂西安·德斯坦熱（Lucien Destange）設計建造。透過秘密通道，金髮女郎得以神出鬼沒。謝爾斯喬裝成新秘書滲入德斯坦熱府邸，最終確認「金髮女郎」正是那位「足不出戶」的深色頭髮女兒——克洛蒂爾德·德斯坦熱（Clotilde Destange）。她是羅蘋的愛人，為愛人不惜殺人、竊鑽，卻將良心的掙扎藏在一雙淚眼背後。

謝爾斯試圖挾持克洛蒂爾德，不料早在他對話途中，克洛蒂爾德已以打電話給裁縫師為名，暗中通報羅蘋——那個「計程車司機」便是羅蘋本人！謝爾斯被強行載往諾曼第海邊，押上蒸汽遊艇驅逐出境。而羅蘋最終仍遭謝爾斯反追，在克雷沃路的秘密巢穴被包圍，卻憑電梯一計脫逃。謝爾斯以「交還克洛蒂爾德自由」換回真正的藍鑽，隱藏在羅蘋手杖頂端的空心球中。

第二篇章：猶太油燈（The Jewish Lamp）

倫敦歸來的謝爾斯再度赴巴黎，為德·安布拉瓦爾男爵調查一場看似外侵型竊盜的案件：有人破窗入室，偷走了一盞古董猶太油燈——而燈的底座暗藏一枚價值連城的金奇美拉紅寶翡翠首飾。謝爾斯立即斷定這是內賊之作，外部的梯子痕跡、玻璃切割痕跡，不過是精心佈置的假象。

女家庭教師阿麗斯·德明（Alice Demun）成了嫌疑焦點：謝爾斯在孩子的圖畫字母書裡發現被剪去的字母，拼湊出阿麗斯與「羅蘋」之間以《法蘭西迴響報》（Echo de France）秘密通訊的電報密碼。阿麗斯最終坦白認罪——然而，當男爵質疑一個細節（書房的門從裡上了門閂），謝爾斯驟然醒悟：阿麗斯是無辜的。真正的罪魁，是伯爵夫人蘇珊娜·德·安布拉瓦爾：她被勒索者布雷松（Bresson）掌握了私人書信，委託阿麗斯輾轉聯絡羅蘋，以竊取猶太油燈換回信件。阿麗斯出於對女主人的深厚情誼，主動攬罪。布雷松最後在謝爾斯與加尼瑪追緝下自殺，珍寶沉入塞納河，由謝爾斯打撈尋回。

真相拆解

第一篇章：金髮女郎

真相一：「金髮女郎」的真實身份

  • 線索收斂點：約 75%
  • 答案：克洛蒂爾德·德斯坦熱（Clotilde Destange），著名建築師呂西安之女，羅蘋的秘密愛人。她以三個假名現身：陪伴男爵的「安托瓦內特·布雷阿」（Antoinette Brehat）、推薦伯爵夫人購買藍鑽的「德·雷阿爾夫人」（Mme. de Real）、以及德蒂南辦公室中帶走羅蘋的神秘「金髮女郎」。出場時金髮耀眼，事後恢復本來的深色髮色。

關鍵線索

# 線索內容 出現位置（章節/百分比） 說明
1 金髮女郎的頭髮呈現「金屬般亮澤」，在德蒂南案與藍鑽案均被目擊者描述為同一特徵 第一篇 Ch.1–2 / 約 10–25% 構成同一人「跨案現身」的基本識別特徵
2 三起案件地點——克拉帕依宏路25號、亨利·馬丁大道134號、克羅宗城堡——門楣均刻有「德斯坦熱建築師，1874/1875/1877」 第一篇 Ch.4 / 約 65% 此為核心物理線索：同一建築師→同一祕密通道設計→同一幕後操盤手
3 謝爾斯喬裝入德斯坦熱府邸後，親眼目睹羅蘋以「馬克西姆·貝爾蒙德」之名自由進出，與克洛蒂爾德情深意篤 第一篇 Ch.4 / 約 70% 確認金髮女郎必為府中之人
4 謝爾斯跟蹤一名蒙面女子至一棟公寓，透過滑動牆板發現女子即克洛蒂爾德——她竟直接連通德斯坦熱的藏書圓廳 第一篇 Ch.5 / 約 75% 最後一條關鍵線索：正式確認克洛蒂爾德即金髮女郎

輔助線索

# 線索內容 出現位置（章節/百分比） 說明
1 加尼瑪在男爵手中發現的金髮，被鑑定人認定為「亮金色金屬光澤」，與金髮女郎一致 第一篇 Ch.2 / 約 25% 強化同一人犯案的可能性
2 德·雷阿爾夫人首先向伯爵夫人推薦購買藍鑽，又在伯爵夫人家中偷走藍鑽 第一篇 Ch.2 / 約 30–40% 說明金髮女郎主動布局引導目標購入再竊取
3 克洛蒂爾德「足不出戶」的宅女形象，與每次金髮女郎現身後神秘消失的時間點吻合 第一篇 Ch.4 / 約 68% 反面線索：「足不出戶」的人出不了門……還是根本不用走正門？
4 德斯坦熱的舊帳本裡，有一份「M. B.」（馬克西姆·貝爾蒙德 = 羅蘋）的秘密檔案，記錄了十五棟「改建」建築 第一篇 Ch.5 / 約 79% 說明羅蘋系統性利用這些建築，提供合理的操作框架

假線索

# 線索內容 出現位置（章節/百分比） 誤導方向
1 加尼瑪在茶館設下圈套，引出一位淡金色頭髮、面色蒼白的「真實存在的」德·雷阿爾夫人（珠寶經紀人） 第一篇 Ch.2 / 約 37% 讓讀者以為金髮女郎就是這個真實的珠寶商，加尼瑪的調查宣告失敗——而實際上此女是羅蘋精心安排的替身誘餌
2 男爵臥室外牆的「梯子痕跡」與「地上的洞」，看似有外人翻牆入侵 第一篇 Ch.2 / 約 20% 讓偵察方向偏向外來入侵，實則案發時無人破窗入室
3 克洛蒂爾德的深色頭髮：讀者與謝爾斯都曾因此否定她是「金髮女郎」 第一篇 Ch.4–5 / 約 65–70% 謝爾斯後來嘲自己：「金髮女郎案發後還能繼續頂著金髮嗎？！」

真相二：「藍鑽」的真實下落

  • 線索收斂點：約 93%
  • 答案：布萊興領事牙粉瓶中找到的是複製品（鑽石粉高溫重熔而成的仿品）；真正的藍鑽，自金髮女郎「未能」從男爵手指取下之後，始終在羅蘋手中。他將真鑽藏在自己的手杖頂端——一個中空的旋轉把手球之內。最終謝爾斯以克洛蒂爾德的自由換取真鑽。

關鍵線索

# 線索內容 出現位置（章節/百分比） 說明
1 謝爾斯在火車上取出伯爵夫人的戒指鑑定，當場斷定：「這是假的。」 第一篇 Ch.3 / 約 42% 建立「真鑽仍在羅蘋手中」的前提
2 羅蘋親口承認仿鑽調包計，說明金髮女郎（克洛蒂爾德）偷走了真鑽，再用仿品塞入布萊興行李 第一篇 Ch.3 / 約 43% 確認事件的完整邏輯——但真鑽究竟藏在哪，此時仍未揭曉
3 羅蘋落網後，從角落取出手杖，指示謝爾斯旋轉底部鐵套、打開頂端把手球 第一篇 Ch.6 / 約 93% 最後一條關鍵線索：真鑽藏身之處終於揭曉

2 羅蘋對謝爾斯說：「只要你交出克洛蒂爾德的自由，我就交出你想要的。」——說明他知道真鑽的「交換價值」 第一篇 Ch.6 / 約 91% 暗示真鑽是可交易的具體資產

真相三：羅蘋如何在密室中消失——建築師的秘密通道

  • 線索收斂點：約 65%
  • 答案：呂西安·德斯坦熱建築師在設計三棟建築時，皆暗設了連通相鄰建築的秘密通道、暗梯或牆板滑道。羅蘋多年來以「馬克西姆·貝爾蒙德」之名協助德斯坦熱完成舊案後期施工，得以掌握這些通道的全部細節，並加以利用。

第二篇章：猶太油燈

真相一：猶太油燈盜案的真相——不是外賊，是恩怨情仇

  • 線索收斂點（表層：外部入侵之假）：約 15%；深層（真正主謀）：約 95%
  • 答案：
  • 表層假象：梯子、玻璃切割、地上的洞……全是仿造。謝爾斯第一次到場即識破這是內部人所為。
  • 深層真相：德·安布拉瓦爾男爵夫人蘇珊娜曾寫下私人書信被勒索者布雷松掌握。為贖回信件，她輾轉透過女家庭教師阿麗斯·德明聯絡羅蘋，以偷竊猶太油燈（內藏翡翠金奇美拉）作為支付條件。阿麗斯為了保護主人，最終自願認罪，卻以一個細節露出了馬腳。

關鍵線索

# 線索內容 出現位置（章節/百分比） 說明
1 梯子留下的孔洞，陽台下與欄杆邊的距離不一致，且形狀完全相同——顯然是用同一根木樁偽造的 第二篇 Ch.1 / 約 15% 謝爾斯從花園撿回「製洞木樁」，宣告外賊說謊
2 阿麗斯在孩子字母書上剪去特定字母，謝爾斯拼湊出「REPONDEZ……ECH 237」——即「回覆至《法蘭西迴響報》237號」 第二篇 Ch.1 / 約 78% 確認阿麗斯與羅蘋的秘密通訊，案件核心浮現
3 男爵陳述：書房的門當晚從裡面上了門閂——若阿麗斯從書房偷燈，必有人從裡面開門放她進去 第二篇 Ch.2 / 約 95% 最後關鍵線索：打破阿麗斯認罪的邏輯，謝爾斯轉向——真正的主謀是女主人本身

輔助線索

# 線索內容 出現位置（章節/百分比） 說明
1 盜案第一晚，賊人只偷油燈；第二晚真正的外部盜賊（布雷松的人）卻偷了煙盒與項鍊等值錢物件——說明兩次盜案是截然不同的性質 第二篇 Ch.1 / 約 60% 對比兩次行竊的範圍，可推出第一次只針對「有特定用途」的油燈
2 布雷松在塞納河邊拋下包裹後返回，又被另一名跟蹤者緊盯——顯示他自己也被人監視，與案件另有糾葛 第二篇 Ch.1 / 約 82% 說明布雷松不只是買主，他是整個勒索鏈中的一環
3 小孩亨麗葉特向謝爾斯透露：女家庭教師習慣用剪報字母拼貼信件，不是孩子自己剪的 第二篇 Ch.1 / 約 74% 為謝爾斯提供破案的切入點

1 模擬的梯子痕跡、切割的玻璃窗格、陽台的刮痕 第二篇 Ch.1 / 約 10% 設計成標準外來竊盜現場，讓警察（以及讀者）直接落入「尋找外部入侵者」的慣性思維
2 阿麗斯·德明在審訊中沉著不露，始終不為自己辯白，連謝爾斯也相信她是羅蘋培訓出來的老練同謀 第二篇 Ch.1–2 / 約 70–90% 讓讀者與謝爾斯一道誤判方向：以為真相已被揭開，實則阿麗斯只是一個以身護主的無辜女孩
3 布雷松的自殺被塑造成「慌亂逃竄的罪犯落網前的了斷」，暗示他才是主謀 第二篇 Ch.1 / 約 84% 讓讀者認為案件已告終結，忽略布雷松不過是勒索者，而非盜賊本身

推理路徑重建

第一篇章：金髮女郎的偵破路徑

一條謝爾斯得以走通、讀者理論上也能跟隨的路：

讀者的第一個機會出現在約 25%：加尼瑪的報告指出安托瓦內特·布雷阿的頭髮與金髮女郎「完全一致」。此時細心的讀者應意識到：這兩個名字很可能是同一人。

第二個機會在 35% 前後：德·雷阿爾夫人主動建議伯爵夫人購買藍鑽，之後又神秘地在伯爵夫人宅邸「竊回」——行徑如出一轍。「金髮女郎」已在三起案件中留下統一的行動模式。

真正讓謝爾斯開竅的節點，是在 65%——建築師刻字的發現。

在此之前，謝爾斯已在克拉帕依宏路 25、23 號（威爾遜手臂骨折後，謝爾斯獨自望見這行刻字）注意到「德斯坦熱建築師」。接著他奔向亨利·馬丁大道驗證，再電話確認克羅宗城堡——三點連線，一個共同建築師的存在將三起在空間上毫無關聯的案件串成一條因果鏈。

此後，謝爾斯的路徑完全可被讀者跟隨： - 建築師 → 找到本人 → 滲入府邸 → 發現羅蘋以化名在此自由進出 → 發現克洛蒂爾德的秘密房間（通向另一棟建築）→ 確認金髮女郎身份

值得注意的是：盧布朗在謝爾斯喬裝入府後立即描寫「克洛蒂爾德的身影」，給了讀者清晰的視角提示。但唯一讓讀者「跟不上」的，是謝爾斯如何在那麼短的時間內「想到」建築師刻字——這個直覺跳躍出現得相對突然，即便謝爾斯自己也說不完全清楚為何在威爾遜骨折的那一刻突然想通。

第二篇章：猶太油燈的偵破路徑

這一篇章的精彩之處，在於有兩層真相：

第一層（約 15%）：假的外部盜賊 謝爾斯不到一小時就識破假象，這條路對讀者完全開放。測量孔洞距離（陽台下 9 吋，欄杆邊 11 吋，形狀雷同卻不平行）、在花園找到偽造木樁——都是讀者本可發現的「可見線索」。謝爾斯的推論是：真正的竊賊熟悉每件物品的位置，說明他曾在此居住或工作。

第二層（約 95%）：誰才是真正主謀 阿麗斯的認罪讓讀者（以及謝爾斯）都一度放鬆。然而男爵一個不起眼的陳述——「書房的門從裡上了門閂」——在幾乎最後一刻戳破了阿麗斯的謊言。

這個細節本身不難理解：如果阿麗斯從書房偷燈，書房的門必然是從裡面打開讓她進去的。而那時書房裡只有男爵夫婦。所以是夫婦其中一人讓阿麗斯入內——或者，根本是夫婦其中一人自己偷了燈，然後把油燈交給阿麗斯帶出。

謝爾斯轉身望向男爵夫人時，她的臉色已說明一切。

這條「反轉」對讀者而言並非不可能，但需要讀者在聽到阿麗斯認罪後，還能保持對「門閂細節」的警覺。盧布朗在這裡玩了一個「資訊過載」的把戲：阿麗斯看似完美的坦白，掩蓋了這個唯一的邏輯漏洞。

補充說明

《金髮女郎》在亞森·羅蘋系列中的特殊地位

《金髮女郎》（或以英文版書名稱之：《Arsène Lupin versus Holmlock Shears》）是盧布朗系列作品中一個決定性的轉折點：羅蘋不再只是愚弄無能警察的紳士盜，而是正面迎戰一個旗鼓相當的對手。

盧布朗的「謝爾斯」顯然是柯南·道爾筆下福爾摩斯的直接挪用——名字只改了幾個字母，「威爾遜」對應「華生」，「謝爾斯的二百一十九號派克街」對應「貝克街二百二十一號」。這種「跨文本的戲謔」本身就是一種文學玩弄：盧布朗在挑釁柯南·道爾，也在向讀者宣告羅蘋可以打敗英國最聰明的偵探。

然而有趣的是，盧布朗並未給羅蘋一面倒的勝利。謝爾斯幾乎每一步都被羅蘋玩弄，卻也從未真正被擊倒——他找出了建築師線索，確認了金髮女郎身份，追回了真正的藍鑽，最終也成功讓羅蘋在第二局被捕（儘管羅蘋仍以一貫的戲劇性手法脫逃）。這種「棋逢對手，互有勝負」的設計，是《金髮女郎》最動人的筆法之一。

推理設計的結構特點

本書不是傳統的推理小說，而是一部「追逐與博弈的文學。」

在傳統偵探小說中，讀者的樂趣來自「跟隨偵探解謎」。在本書中，讀者同時跟隨三條視角——謝爾斯（正在追）、羅蘋（正在逃並反追）、以及超然的作者旁白（帶著幾分欣賞的中立）。這種三角視角讓本書的「謎」不只是「兇手是誰」，更是「下一步誰能先棋先」。

盧布朗在設計上有幾個值得注意的手法：

  1. 「假被捕」雙重結構：第一篇章謝爾斯以為逮到了金髮女郎（假的），以為羅蘋被加尼瑪包圍（真的，但羅蘋仍逃走）；這種「剛抓到又跑掉」的節奏，刻意讓讀者在「快贏了」與「又輸了」之間來回，製造閱讀上的焦灼感。

  2. 解謎節奏的刻意錯位：本書最大的謎（建築師秘密通道）在全書三分之二時才被謝爾斯揭開，但揭開之後謝爾斯的行動極為迅速，使「知道了關鍵事實」到「案件接近收尾」之間的落差變得很短，給讀者一種後半段「怎麼那麼快」的衝刺感。

  3. 以「戀愛」承載「罪行」：克洛蒂爾德為了羅蘋的愛，不惜殺人竊鑽，卻始終保持一種幾乎宗教式的平靜與凜然。第二篇章的阿麗斯則以摯友之情為女主人自願入罪。這兩位女性的「自願犧牲」，都使得傳統意義上的「揭露兇手」顯得殘忍而複雜——謝爾斯最終選擇對兩人「睜一隻眼閉一隻眼」，恰恰是作者藉此質疑：「正義」究竟是在揭穿真相，還是在毀掉一段人情？

與系列其他作品的比較

相較於盧布朗的短篇羅蘋故事，《金髮女郎》的推理密度更高：短篇通常只有一條謎線，本書則同時操控三條（金髮女郎身份、藍鑽下落、建築師祕密），並且在第二篇章後設一道更精巧的「雙重反轉」。

相較於柯南·道爾的福爾摩斯，謝爾斯的思維路徑被描寫得更外化（他常常大聲說出推論過程），讀者跟隨難度因此稍低；然而羅蘋的存在讓謝爾斯時刻「被監視」、「被反制」，削弱了傳統偵探的全知感，使讀者在認同偵探的同時，又忍不住為那個笑著走鋼索的賊人心跳加速。

給台灣讀者的補充

「霍姆洛克·謝爾斯」（Holmlock Shears）是盧布朗對夏洛克·福爾摩斯（Sherlock Holmes）的仿諷，名字拼法稍作更動。原著法文版用的是「Herlock Sholmès」，更為直白。台灣較早的中譯本有時直接譯為「夏洛克」或「福爾摩斯」，但嚴格而言這兩個角色在著作權與法律上是不同人物——柯南·道爾生前曾就此向盧布朗提出抗議，促使法文再版時將名字改為「Holmlock Shears」。

「猶太油燈」（Jewish Lamp，法文 Lampe Juive）是希伯來傳統中常見的Hanukkah油燈形制，在十九世紀末的歐洲古董市場頗受珍視。盧布朗選擇這個器物，除了其「藏物於燈」的實用功能外，也帶有當時法國社會對「東方異文化神秘感」的浪漫投射。

「藍鑽」（Blue Diamond）的故事背景指向歷史上著名的「法國藍」（French Blue）——曾屬路易十四，後來成為「希望鑽石」（Hope Diamond）的前身——盧布朗巧妙借用這段真實歷史傳說，為虛構的珍寶賦予了幾分現實的量感。
