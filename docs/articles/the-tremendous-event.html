驚天大事件（The Tremendous Event）— 推理分析

基本資訊

  • 作者：莫里斯·盧布朗（Maurice Leblanc）
  • 出版年：1922年
  • 類型：長篇冒險推理小說
  • 偵探角色：無（主角 Simon Dubosc 兼具行動英雄與業餘推理者的角色）
  • 核心謎團類型：whodunit + howdunit + whydunit（三重謎團交織於大地殼災難背景中）

故事大綱

1922年，英法海峽因古地質斷層（盧布朗稱之為「盧昂斷層」）突然上升，形成一片連接法國迪耶普（Dieppe）到英格蘭黑斯廷斯（Hastings）的新陸地——「諾曼第地峽」。這是改變歐洲政治地理的世紀大事。

法國青年 Simon Dubosc 正在追求英國貴族女兒 Isabel Bakefield，卻遭其父以「先成就英雄偉業再談婚事」拒絕。大地震當夜，Simon 沿著浮出海面的新陸地徒步走到了英格蘭，成為「第一個徒步跨越海峽的人」。

然而就在這趟征途中，一連串謀殺事件隨之展開： - 印裔演員 Badiarinos 在新土地上遭人刺背身亡，身旁留下橡膠底鞋印與一枚拿破崙金幣 - Isabel 給 Simon 的密信遭人攔截，信使（侍女）將信交給了自稱是 Simon 傳話人的「Rolleston 先生」 - 持信者試圖刺殺 Simon，卻刺錯了隔壁房間（44 號而非 43 號）的無辜房客

嫌疑人指向 Simon 的英格蘭朋友 Edward Rolleston——他酗酒成性、行跡不定。但 Simon 直覺無法相信老友是兇手。

真相是：那個人不是 Edward，而是他的表兄弟 Wilfred Rolleston——一個外貌相似、已墮落為酒精中毒偏執狂的罪犯。Wilfred 垂涎 Isabel，招募匪幫、劫持 Lord Bakefield 父女、在新土地的廢棄輪船上稱王，用黃金噴泉統治一支亡命之徒軍團。

Simon 聯合印裔半血演員 Antonio（Lynx-Eye）展開救援；途中又與神秘的墨西哥裔女演員 Dolores 糾纏，她因愛慕 Simon 而故意誤導追蹤路線。最終 Simon 修復墜毀飛機飛抵戰場，在 Antonio 的配合下解救了 Isabel，並阻止了一場法英兩國軍隊的衝突，成為「新領土高級專員」。

真相拆解

真相一：殺手身分——Wilfred Rolleston 而非 Edward Rolleston（whodunit）

  • 線索收斂點：約 55%
  • 答案：凶手是 Wilfred Rolleston，Edward 的表兄弟，二人外貌極為相似，但性格截然相反。Wilfred 已淪為酒精中毒的偏執狂罪犯，以刺背方式殺人（高挑身材讓他可以從上方俯角插刀）。

真相二：信件如何遭攔截，Simon 如何被誤刺（howdunit）

  • 線索收斂點：約 41%
  • 答案：Isabel 的信由侍女送至酒店，Wilfred Rolleston 攔截侍女，謊稱 Simon 在睡覺、他是傳話人，收下信件並付給侍女一枚金幣（同款拿破崙 1807 年版）。讀完信後，他去敲 44 號房的門（誤認為是 Simon 的房間），刺傷了開門的無辜房客。Simon 其實住在 43 號房。

真相三：Dolores 的秘密——為愛誤導（whydunit）

  • 線索收斂點：約 64%
  • 答案：Dolores 在清晨獨自探索時發現了 Rolleston 的足跡，清楚知道追蹤方向——但她故意隱瞞，改而帶領 Simon 沿「海底電纜」走向法國（相反方向），以延長她與 Simon 獨處的時間。她深深愛上了 Simon，從第一眼見到他便如此。

推理路徑重建

第一條路徑：識破「Rolleston」真正身分

讀者在 41% 左右（Antonio 揭示金幣的連結，凶手描述完整）已掌握兩個相互矛盾的訊息： 1. 凶手是「Rolleston」（物證：金幣、橡膠鞋底） 2. Simon 堅信 Edward Rolleston 無辜（性格線索：他對 Simon 的真誠情誼）

這兩個訊息本身是一條重要的推理路口：如果 Simon 的判斷正確，那麼必然存在另一個「Rolleston」。此時仔細的讀者若注意到 Antonio 對凶手的描述（高、蒼白、駝背）與 Edward 的外貌一致，應能察覺：外貌如此相似的人，在英格蘭很可能是近親。

到 55% 處（受傷的 Edward 在殘骸旁，Antonio 確認「他不是那個人」）線索完整收斂，表兄弟 Wilfred 的身分才算確定可推論。

第二條路徑：信件攔截之謎

金幣是最關鍵的實物連結。當 Antonio 展示侍女收到的小費金幣（拿破崙 1807 年版）與 Simon 在謀殺現場拾到的金幣完全一致，讀者在 41% 左右已能推導：

謀殺者 = 攔截信件的人 = 刺傷了錯誤房間住客的人

攔截信件的動機（知道微型肖像的存在 + 知道 Simon 是情敵）也一併清晰。

第三條路徑：Dolores 的背叛

這條路徑最難破解，因為作者刻意將她的情感伏筆以「奉獻與保護」的外衣包裹。關鍵節點在於她的腳印——Simon 從物理證據推斷她「曾單獨到過 Rolleston 的露宿地點，卻沒有告訴他」。這個推理在 63% 才具備可操作性，因為需要讀者記住早先她說過「今早我已探查了附近地形」（Part 2 Ch.2 開頭），再對照稍後的腳印發現，才能拼出她知情不報的事實。

補充說明

這不是一本純推理小說——而是推理包裝的冒險史詩

《驚天大事件》在類型上更接近愛德華時代的冒險小說（adventure novel），而非古典推理小說。盧布朗把推理元素（謀殺、身分誤導、陰謀）嵌入一個地殼大災難的宏觀背景中，產生了一種獨特的閱讀體驗：讀者同時需要應對「誰是凶手」和「整個英法海峽正在天崩地裂」兩個維度的緊張感。

這種設計使謎團的推理壓力相對較低——因為讀者的注意力被奇景（新土地、黃金噴泉、廢船王國）分散了——但也因此讓謎團的揭露更具情感衝擊力。

身分替換：雙 Rolleston 的設計

盧布朗在《亞森·羅賓》系列中以「完美偽裝」聞名；在本書中，他用了一個更優雅的手法——根本不需要偽裝。Wilfred 和 Edward 的外貌天然相似，讓所有目擊者（Antonio、侍女）的描述都指向 Edward，卻偏偏是另一個人。這個「先天誤導」的設計比任何精心化妝更有說服力，因為目擊者的描述是真實的，只是對象被搞混了。

這個手法日後在推理文學中被廣泛使用，但本書作為 1922 年的作品，其先見之明值得肯定。

Dolores 這個角色：推理之外的文學意義

Dolores 是全書最複雜的人物，比反派 Wilfred 更立體。她的「背叛」其實只是愛情的盲目，而她最終選擇犧牲自我利益、獨自趕去向法國軍隊求援，救了 Simon 和 Isabel 的性命——這個結局讓她的「自私」獲得了昇華。

她在最後無聲騎馬離去、連眼神都不給 Simon 的那一幕，是盧布朗在 1920 年代罕見的現代女性書寫：她付出了一切，但拒絕成為任何男人的附屬品。

與盧布朗其他作品的比較

亞森·羅賓系列 驚天大事件
核心謎團 詐騙 / 竊盜 / 身分謎題 謀殺 / 身分誤導
主角性質 紳士怪盜（亦正亦邪） 正直英雄（純粹善良）
世界觀 巴黎上流社會 後地質災難的無政府荒原
敘事野心 精妙的情節機關 地緣政治寓言 + 個人英雄主義

本書是盧布朗罕見的「正面英雄」作品——Simon Dubosc 沒有任何道德模糊，是一個完全正派的人物。這讓推理的驚喜感降低（沒有亞森·羅賓式的「誰是好人誰是壞人」反轉），但故事的情感重心更為清晰。

對台灣讀者的時代補充

本書出版於 1922 年，彼時英法「跨海峽隧道」的設想已流傳數十年（最終在 1994 年建成）。盧布朗把「人工海底隧道」的夢想轉化為「自然地質災難造就的陸橋」，是一個聰明的科幻轉化。書中對新土地的描寫（海底沉積物、古老貝殼層、遠古人類遺跡）顯示盧布朗認真研究了地質學，而他藉「老沙石教授」之口對斷層構造的解說，在 1920 年代是相當通俗精準的科學科普。

黃金噴泉的設定（古代沉船寶藏被地熱噴泉從海底沖出）更是帶有一種豪氣的浪漫主義——這在嚴肅的推理小說中幾乎是不可能出現的元素，但盧布朗就是能把它寫得讓人信服。
